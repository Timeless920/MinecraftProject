# Arsenal 1.0.0

[Скачать готовый мод — arsenal-1.0.0.jar](https://github.com/Timeless920/MinecraftProject/raw/refs/heads/arsenal-download/arsenal-1.0.0.jar)

Требования: Minecraft 1.21.1, NeoForge 21.1.264 (ветка 21.1), Java 21.
Скачайте JAR и поместите его в папку `mods` своего экземпляра Minecraft.
Для многопользовательской игры установите мод также на сервер.

Мод содержит 24 оружия ближнего боя, 5 луков, 5 арбалетов, станок и систему улучшений.

Проверено: Gradle build, генерация данных, 19 серверных GameTest, запуск выделенного
сервера, сетевой запрос статуса и штатная остановка. Клиентский GUI вручную не проверялся.
